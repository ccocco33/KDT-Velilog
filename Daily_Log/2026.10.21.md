## memory
ram (random access memory)
    - 이전에는 순차로 접근했음 ex: 카세트테이프
    - sram
        - chache(캐시)메모리
        - data memory
        - 속도 빠름
        - cellsize 큼 -> 집적도 낮음
        - 전력 소모 큼()
    - dram
        - 속도 느림
        - 사이즈 작음 -> 집적도 높음
        - 전력 소모 작음
    - 주소가 있다.
    - clk,rst가 없다
rom (read only memory)
    - 프로그램(os, application)
    - 전원이 꺼져도 지워지지 않는 메모리
    - = flash memory
    -

(f/f) register
- 속도 가장 빠름(cpu연산에 사용되니까 얜 빨라야함)
- 크기 제일 크다.(f/f d래치 2개임)
- 천력 소모 가장 큼
