# HC-SR04 초음파 거리 센서

## 원리
- 40kHz 초음파를 쏘고 반사되어 돌아오는 시간으로 거리 측정
- Trig에 10µs HIGH → 초음파 발사 → Echo가 HIGH인 시간 = 왕복 시간
- **거리(cm) ≈ 시간(µs) ÷ 58**

## 사양
| 항목 | 값 |
|---|---|
| 전압 / 전류 | 5V / 약 15mA |
| 측정 거리 | 2 ~ 400cm (안정 구간 ~250cm) |
| 분해능 | 약 3mm |
| 측정 각도 | 약 15° |
| 핀 | VCC, Trig, Echo, GND |
| 측정 주기 | 60ms 이상 권장 |

## 장점
- 매우 저렴, 사용 간단
- 색상·투명 물체(유리)·조명 영향 없음

## 단점
- 빔이 넓어 방향 정밀도 낮음
- 천·스펀지는 흡수, 비스듬한 면은 반사 실패
- 온도 영향 있음 (음속 = 331.3 + 0.606 × T)
- 2cm 이내 사각지대, 측정 속도 느림
- 여러 개 동시 사용 시 간섭 → 순차 측정 필요
- Echo 출력 5V → 3.3V 보드(ESP32, 라즈베리파이)는 전압 분배 필요

## 유사 초음파 센서
| 센서 | 특징 |
|---|---|
| HC-SR04P / RCWL-1601 | 3.3~5V 겸용 |
| US-100 | 온도 보정 내장, UART 지원 |
| JSN-SR04T | 방수형, 최소 거리 20~25cm |
| Parallax PING))) | 신호 핀 1개, 품질 안정 |
| SRF02 / SRF10 | I2C 통신 |
| MaxBotix MB1000 | 산업용 고품질, 고가 |

## 활용 사례
- **취미·교육:** 장애물 회피 로봇, 전자 줄자, 거리 반응 악기
- **생활·IoT:** 자동 쓰레기통, 물탱크·쌀통 잔량 측정, 주차 보조, 재실·출입 감지, 자동 손 소독기
- **실제 제품(같은 원리):** 자동차 후방 감지기, 로봇청소기 보조 센서, 산업용 레벨 센서, 드론 착륙 고도 측정
- 수 cm~수 m 범위에서 **대략적인 거리·물체 유무**만 알면 될 때 적합 (정밀 측정은 ToF·LiDAR)

## 팁
- 튀는 값은 여러 번 측정 후 **중앙값** 사용
- `pulseIn()`에 타임아웃 지정 (예: 30000µs)




# 크로스토크(Crosstalk) 노이즈

## 정의
- 원래 받아야 할 신호가 아닌 **다른 신호가 섞여 들어오는 현상**
- 어원: 전화선 혼선 (옆 회선 통화가 들림)

## 초음파 센서에서의 크로스토크

### 1. 센서 간 크로스토크
- HC-SR04는 모두 **같은 40kHz** 사용
- 여러 개를 동시에 쏘면 다른 센서의 초음파를 자기 반사파로 착각
- 결과: 실제보다 가깝거나 엉뚱한 거리 측정

### 2. 센서 내부 크로스토크
- 송신 초음파가 물체에 닿기 전 기판·케이스를 타고 수신부로 직접 유입
- 발사 직후엔 수신 무시 필요 → **사각지대 발생 원인**
  - HC-SR04: 약 2cm
  - JSN-SR04T(송수신 일체형): 진동자 잔향 때문에 20cm 이상

### 해결 방법
- **순차 측정**: 한 센서 측정 후 잔향 사라질 때까지(약 30~60ms) 대기 후 다음 센서
- 센서 방향 분산, 칸막이 설치
- 고급 센서(MaxBotix 등): 고유 신호 패턴으로 자기 신호만 구별

## 전자회로에서의 크로스토크
- 나란한 전선·PCB 배선 사이에서 **전기장·자기장 결합**으로 잡음 유도
- 예: 센서 신호선을 모터선과 함께 묶으면 모터 잡음이 Echo 선에 섞여 값이 튐
- 대책
  - 배선 짧게
  - 신호선과 전원·모터선 분리
