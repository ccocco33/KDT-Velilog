### 4상태 : {1, 0, x, z}  (시뮬레이션에서 x값 주의)
    - x : unknown
        - 0인지 1인지 모름
        - 초기화 안 된 reg, 0과 1이 충돌하는 net 등에서 발생
    - z : 끊어진 상태, high impedance
        - 아무도 구동하지 않음
        - 연결 안 된 입력, 트라이스테이트 버퍼의 출력 off 상태

### 3상태 (tri-state) : {0, 1, z}
    - 트라이스테이트 버퍼 출력
        - enable = 1 → 입력 그대로
        - enable = 0 → z
    - z는 bus 제어할 때 많이 쓴다
        - 여러 장치가 한 선을 공유, 말하는 장치 하나만 enable
        - (예) assign bus = en ? data : 1'bz;

### multiple drivers : 하나의 net을 여러 소스가 동시에 구동
    - wire / tri
        - 한쪽이 z → 다른 쪽 값을 따름
        - 0과 1이 충돌 → x
    - wand / triand : 여러 구동값을 AND로 결합 (wired-AND)
    - wor / trior : 여러 구동값을 OR로 결합 (wired-OR)

### tri와 wire : 기능은 완전히 같음 (tri로 하는 거 wire로도 가능)
    - tri는 "여러 드라이버가 공유하는 버스"라는 의도를 표시하는 용도
    - (예)
        wire        w_sum;      // 일반 연결선
        tri  [7:0]  data_bus;   // 트라이스테이트 버스라는 의도 표시

### supply0, supply1
    - GND(0), VCC(1)에 고정 연결된 net

### pulldown / pullup
    - net이 z(아무도 구동 안 함)일 때 기본값을 0 / 1로 만들어 줌
    - tri0 / tri1 : pulldown / pullup이 걸린 tri (z일 때 0 / 1)
    - 주로 외부 핀(버튼, 버스)에 사용
    - 칩 내부의 미사용 입력은 1'b0처럼 상수를 직접 연결

### trireg (커패시터)
    - 구동이 끊겨 z가 되어도 마지막 값을 저장하고 있는 net (전하 저장)

### net 자료형
    - 문법
        net_type [signed] [range] [#(delay)] net_name [array] {, net_name [array]};
    - (예)
        wire signed [7:0] #5 w_a, w_b;
    - delay
        - 시뮬레이션은 기본적으로 딜레이 없음 (이상적인 동작)
        - 실제 칩에서는 딜레이가 생김 → 시뮬에서도 흉내 내려고 delay를 줌
        - ※ 합성 시에는 무시됨

### BJT / CMOS
    - 요즘 디지털 IC는 거의 다 CMOS 사용

### variable 자료형 : reg, integer, real, time, realtime
    - 특징
        - 절차적 할당문(always, initial 안의 =, <=)의 실행에 의해 값이 바뀐다
        - 다음 할당까지 값을 유지 (= memory)
        - register용으로도, 값을 유지시키는 용으로도 쓴다 (무조건 register 생성 아님)
            - (예) always @(*) 조합 회로 안의 reg → 합성하면 FF가 아니라 LUT가 됨
    - 종류
        - reg
            - 기본 unsigned, 폭 지정 가능, 초기값 x
        - integer
            - 32bit, 정수형 값 취급, signed reg로 취급
            - 연산 결과는 2의 보수
            - 주로 for문 반복 변수로 사용
        - time
            - 64bit unsigned
            - 시뮬레이션 시간을 처리·저장 → 진단, 디버깅용 ($time과 함께 사용)
            - 64bit reg와 동일
        - real
            - 64bit 배정도 부동소수점 (실수)
            - 합성 불가, 시뮬레이션 전용
            - 비트 / 부분 선택 불가, 초기값 0.0
        - realtime
            - real과 동일
            - 시뮬레이션 시간을 실수로 저장할 때 사용 ($realtime과 함께)

### parameter : variable 또는 net 범주에 속하지 않는 상수값
    - 값 변경 방법
        - defparam문 (요즘 잘 안 씀)
        - 모듈 인스턴스의 parameter 덮어쓰기 → #(.WIDTH(16)) 방식 권장
    - 자료형과 범위 지정 가능
        - (예) parameter [7:0] MAX = 8'd100;
    - parameter vs localparam
        - parameter : 외부에서 변경 가능
        - localparam : 외부에서 변경 불가
    - (예)
        module adder #(parameter WIDTH = 8) (...);
        adder #(.WIDTH(16)) U_ADD (...);   // 16비트로 덮어쓰기

### 연산자
    - 결합, 반복 : {}, {{}}
        - {a, b} : a와 b를 이어 붙임
        - {4{1'b1}} = 4'b1111
    - 산술 : +, -, *, /, %, ** (거듭제곱)
        - % : 나머지  (예) 17 % 5 = 2
    - 관계 : >, <, >=, <=
        - 결과는 1bit (1, 0, 또는 x)
    - 논리 : && (AND), || (OR), ! (NOT)
        - 전체 값을 참/거짓으로 보고 결과는 1bit
    - 비트 : ~ (부정), & (and), | (or), ^ (xor), ~^ (xnor)
        - 비트끼리 각각 계산, 결과는 같은 폭의 벡터
    - ※ 비트 연산 vs 논리 연산
        - 비트 연산 : 각 비트를 따로 계산
        - 논리 연산 : 값 전체가 0이면 거짓, 0이 아니면 참
        - (예) a = 4'b0101, b = 4'b1010
            a & b  = 4'b0000   (비트 AND)
            a && b = 1'b1      (둘 다 0이 아니므로 참)
    - 등가 : ==, !=
        - x나 z가 섞이면 결과가 x
    - case 등가 : ===, !==
        - 4상태인 x와 z까지 정확히 비교
        - 결과는 항상 0 또는 1 (주로 테스트벤치에서 사용) 
        - 합성 툴에 따ㄴ라서 안될 수 도 있음
    - 축약 (reduction) : 벡터의 모든 비트를 하나로 연산 → 1bit 결과
        - &a : 전부 1인지
        - |a : 1이 하나라도 있는지
        - ^a : 1의 개수가 홀수인지 (패리티)
        - ~&, ~|, ~^ : 위 결과의 반전
    - 시프트 : bit를 밀어버리는 것
        - 논리 : <<, >>
            - 빈자리를 0으로 채움
        - 산술 : <<<, >>>
            - >>> : 빈자리를 부호 비트로 채움 (부호 확장, signed일 때만)
            - <<< : <<와 동일 (오른쪽 빈자리는 항상 0)
        - (예)
            8'sb1000_0000 >>> 2 = 8'b1110_0000
            8'b1000_0000  >>  2 = 8'b0010_0000
    - 조건 (3항 연산자) : 조건 ? 참일 때 값 : 거짓일 때 값
        - (예) assign y = sel ? a : b;   // 2x1 MUX
        - 1만 참 , x or z는 거짓
    - event or (= ',')
        - 감도 리스트에서 사용
        - (예) @(a or b) = @(a, b)
